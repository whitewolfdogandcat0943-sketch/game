# 立ち絵の差し替え

ここに画像を置き、`js/data/portrait-assets.js` に1行足すと、その人物だけ画像に切り替わります。
置かなければ、これまでどおりコードで描いたドット絵が使われます。

## 手順

1. 画像をこのフォルダに置く（PNG、背景は透過）
2. `js/data/portrait-assets.js` を開き、その人物の行のコメントを外す

```js
G.PORTRAIT_ASSETS = {
  garo: { bust: 'assets/portraits/garo_bust.png', full: 'assets/portraits/garo_full.png' },
};
```

3. ブラウザを再読み込みする

`bust` だけ、`full` だけの指定でも構いません。書いていない方は手続き生成が使われます。
パスが間違っていたり画像が無かった場合も、黙って手続き生成に戻ります。

## サイズ

| 種類 | 用途 | 縦横比 | 推奨 |
| --- | --- | --- | --- |
| `bust` | 会話画面 | 13 : 15 | 520 × 600 |
| `full` | パーティ一覧・転職の祭壇・職業選択・図鑑 | 4 : 7 | 480 × 840 |

- **背景は透過**にしてください。暗い背景の上に置かれます。
- ドット絵にする場合はCSSで `image-rendering: pixelated` が掛かるので、
  等倍で描いて拡大されることを前提にして構いません。
- 滑らかなイラストの場合は `.portrait.drawn` に対して
  `image-rendering: auto` が当たるようにしてあります。

## id の一覧

`docs/portrait-prompts.md` に、全員分の id と外見の指定がまとめてあります。
生成AIに渡すためのプロンプトもそこに入っています。

主人公は職業ごとに姿が変わるため `hero_swordsman` のように分かれています。
`hero` を指定すると、専用の画像が無い職業すべての既定として使われます。
