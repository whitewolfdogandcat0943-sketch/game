# 相剋のビルドサーガ / BUILD SAGA

ブラウザだけで遊べる、**ビルド構築特化のローグライトRPG**です。
外部ライブラリ・ビルド手順は一切不要。`index.html` を開けばすぐ始まります。

```
git clone <this repo> && cd game
# そのまま index.html をダブルクリック、または
python3 -m http.server 8000   # → http://localhost:8000
```

進行状況（発見したミシック・到達した職業・最深階層・冒険の途中経過）は
ブラウザの localStorage に自動保存されます。

---

## コンセプト

> **組み合わせが職業を拓く。**

装備・アクセサリ4枠・職業パッシブで積み上げた「数値そのもの」が転職条件になります。
会心を極めれば剣聖の道が、反射を極めれば天帝の道が開く ―― どの初級職から始めても、
ビルド次第で全ての最上級職に到達できます。

## 実装した要素

### 1. 多岐にわたるビルド（アクセサリ4枠）

装備スロットは **武器 / 防具 / アクセサリ×4**。
アクセサリ4枠の組み方がビルドの本体で、以下の軸を自由に伸ばせます。

| 軸 | 主な指標 | 代表的な挙動 |
| --- | --- | --- |
| 会心 | 会心率 / 会心ダメージ | 会心時に防御無視、多段攻撃との相乗 |
| 反射 | 反射率 / 反射威力 | 被弾ダメージを跳ね返す。全体化・反射回復あり |
| 範囲 | 波及率 / 範囲威力 | **単体攻撃が他の敵にも波及**する。全体技の威力増 |
| 属性 | 炎・氷・雷・風・光・闇の各ダメージ / 耐性貫通 | 弱点1.6倍、耐性0.55倍を貫通で緩和 |
| アイテム | アイテム威力 / 温存率 | 消耗品が主力火力になる。温存率で消費しない |
| 吸収・堅守 | 吸収 / 被ダメ軽減 / 回避 / バリア | 殴られながら勝つ構成 |

さらに **特殊効果（フラグ）が41種類**あり、数値では表せない挙動を足します。

- 反射の全体化 / 反射ダメージの一部をHPに変換 / ラウンド終了時の棘ダメージ
- 通常攻撃の2分割 / 通常攻撃の全属性化 / 通常攻撃の属性が毎ターン移り変わる
- 会心時に防御無視 / 会心時に追撃 / 各戦闘の初撃が必ず会心
- 素早さや物理防御の一部を攻撃力に変換 / 残りMPの割合で与ダメージ上昇
- 敵が3体以上／1体のみ／瀕死／ボス／状態異常中 のときに与ダメージ上昇
- 魔法スキルの二重詠唱 / 状態異常の周囲への伝播 / 回避時の反撃
- 致死ダメージ耐え / HP50%以下で被ダメ減 / 回復の超過分がバリアになる
- 撃破時にHP回復・MP回復・攻撃力累積・周囲へ爆散
- アイテム効果の再発動 / 戦闘開始時のアイテム補充・バリア展開

### 2. ビルドによる最上級職の解放

職業は **初級職(4) → 上級職(7) → 最上級職(8)** の3段階。
「転職の祭壇」で条件を確認でき、条件を満たした職にその場で転職できます。
**一度就いた職業のスキルは転職後も全て使えます**（前職の基礎能力も15%引き継ぎ）。

| 最上級職 | 主な解放条件 |
| --- | --- |
| 絶影剣聖 | 会心率60% / 会心ダメージ260% / 冒険中に会心60回 / 暗殺者・狂戦士から |
| 鏡獄天帝 | 反射率60% / 物理防御110 / 反射ダメージで8体撃破 / 守護者から |
| 天災嵐王 | 範囲威力80% / 波及率55% / 範囲攻撃で20体撃破 / 嵐使いから |
| 星辰術皇 | 6属性すべて22%以上 / 耐性貫通35% / 魔法攻撃160 / 元素使い・破魔僧から |
| 万象錬成王 | アイテム威力100% / 温存率35% / アイテム25回使用 / 錬金術士から |
| 血喰鬼神 | 吸収35% / 物理攻撃200 / 45体撃破 / 狂戦士・暗殺者から |
| 終焉審判者 | 光+闇の強化合計95% / 被ダメ軽減25% / 破魔僧・神官から |
| 虚無帝 | **ミシックを3個装備** / Lv14 / ミシック3種発見済 |

いずれもレベルとレジェンドアクセサリの装備が追加条件になります。

### 3. アクセサリは3階級

**全138種**あります。

- **通常（72種）** … 素直な数値強化。単一軸の強化、6属性の宝珠・輝石、
  会心×反射のような二軸ハイブリッドまで揃い、ビルドの土台になります。
- **レジェンド（42種）** … クセの強い特殊効果つき。デメリット持ちも多い。
  （例:「断罪者の血盟」会心率+25%・会心ダメ+65%だが最大HP-18%、
  「一騎討ちの証」敵が1体のときのみ与ダメージ+40%）
- **ミシック（24種）** … **戦闘中／冒険中の特殊条件を満たすと「発見」** される最強級。
  一度発見すれば**記録に永続保存**され、以後の冒険でも行商人から入手可能になります。

## グラフィック（すべてコード生成・画像ファイル0枚）

外部アセットを一切持たず、**16×16のドットマップ + HSLパレット**から Canvas で描画し、
dataURL としてキャッシュしています。

- **スプライト20種のアーキタイプ**（粘体・蝙蝠・小型人型・大型人型・骸骨・法衣・鳥・樹木・
  亡霊・岩石・甲冑騎士・四足獣・竜・天使・光球・虚無・蠍・結晶・軽装・重装）を
  敵26種と職業19種に割り当て、色相と瞳・アクセント色で個体を作り分けます。
- ドットマップは**左半分8列だけを記述し右半分は鏡像**として展開します。
  幅が常に16に揃い、生物的な左右対称のシルエットになります。
- 最上級職には**冠のオーバーレイ**が載ります。
- 装備アイコン（剣・鎧・指輪・薬瓶）とマップのノードアイコン（剣・髑髏・宝箱・
  行商の袋・焚き火・鳥居・星・王冠）も同じ仕組みで生成しています。
  属性強化を持つアクセサリは**宝石の色がその属性の色相**になります。

演出は「読みやすさ優先」で控えめに統一しました。

- ダメージ数字のポップアップ（会心は金・反射は紫・範囲は緑・回復は緑・回避はMISS）
- 被弾時のフラッシュ、攻撃時の踏み込み、撃破時の沈み込み
- 待機時のごく浅い上下動（`prefers-reduced-motion` を尊重して自動停止）
- 階層帯ごとの背景（苔むした坑道 → 凍てつく回廊 → 燃える大聖堂 → 星のない深層 → 深淵）

## 遊び方

1. 初級職（剣士・魔術士・盗賊・神官）を1つ選ぶ。
2. 各階層で **戦闘 / 精鋭 / 宝物庫 / 行商人 / 焚き火 / 転職の祭壇 / イベント** から1つを選んで進む。
3. 精鋭・ボス・宝物庫では**3択の報酬**から1つを選ぶ ―― ここでビルドの方向を決める。
4. 戦闘は速度順のターン制。敵をクリックで対象変更、スキル / アイテムで戦う。
   属性の弱点(1.6倍)・耐性(0.55倍)、会心、反射、波及がすべて同じ計算式に乗る。
5. 5階ごとにボス。**25階の「世界の鏡像」を倒せば踏破**、その先は無限の「深淵」。
6. 倒れても、発見したミシックと到達した職業の記録は残る。

## ファイル構成

```
index.html            エントリポイント（依存なし・script順に読み込むだけ）
css/style.css         ダークテーマのUI
js/util.js            乱数・重み付き抽選・DOMヘルパー
js/data/elements.js   属性定義／ビルド指標(modキー)／特殊効果フラグの辞書
js/data/skills.js     スキル（汎用・職業別・最上級職の奥義・敵専用）
js/data/classes.js    職業3段階と解放条件（条件はテスト関数として定義）
js/data/gear.js       武器・防具
js/data/accessories.js 通常/レジェンド/ミシックのアクセサリ
js/data/items.js      消耗アイテム
js/data/enemies.js    敵とボス
js/core/stats.js      ビルド集計（装備・職業・バフ → 派生ステータス）
js/core/unlock.js     職業解放条件／ミシック取得条件の判定
js/core/battle.js     戦闘エンジン（ダメージ・会心・反射・波及・状態異常）
js/core/run.js        冒険の進行（ノード生成・報酬・店・イベント）
js/core/save.js       localStorage への永続化
js/gfx/sprites.js     ドット絵スプライトの手続き生成（敵・職業・アイコン）
js/gfx/fx.js          戦闘演出（ダメージ数字・フラッシュ）と階層背景
js/ui/ui.js           描画ヘルパー（カード・バー・ステータス表）
js/ui/screens.js      各画面の描画
js/main.js            状態管理と画面遷移
```

### バランス設計メモ

敵は「適正階層」からの差分でスケールします（`HOME_FLOOR`）。
上位ティアの敵が初登場した瞬間に数値が跳ね上がらないため、
階層が進むほど一方的に不利になることがありません。
