# 相剋のビルドサーガ / BUILD SAGA

ブラウザだけで遊べる、**ビルド構築特化のパーティRPG**です。
外部ライブラリ・ビルド手順は一切不要。`index.html` を開けばすぐ始まります。

遊び方は2つ。

- **物語モード** … 全6章のストーリーRPG。町とダンジョンを行き来し、仲間を集めて旅をする。
- **試練の塔** … 25階の登り切り勝負（ローグライト）。道は毎回変わり、倒れればそこで終わり。

どちらのモードでも、下に書いたビルドシステムはまるごと共通です。
**難易度は4段（やさしい／標準／高難度／相剋）**から選べ、冒険の途中でも変えられます。

```
git clone <this repo> && cd game
# そのまま index.html をダブルクリック、または
python3 -m http.server 8000   # → http://localhost:8000
```

PCで開発する場合の環境構築（Godot版を含む）は **[SETUP.md](SETUP.md)** を参照してください。

進行状況（発見したミシック・到達した職業・最深階層・冒険の途中経過）は
ブラウザの localStorage に自動保存されます。

---

## コンセプト

> **組み合わせが職業を拓く。**

装備・アクセサリ4枠・職業パッシブで積み上げた「数値そのもの」が転職条件になります。
会心を極めれば剣聖の道が、反射を極めれば天帝の道が開く ―― どの初級職から始めても、
ビルド次第で全ての最上級職に到達できます。

## 物語モード

主人公は灰都ルヴィナの見習い衛士の青年。世界から色と手触りが抜け落ちていく
「**褪せ**」を追って、六つの力の均衡＝「**相刻**」を刻み直すまでの全6章です。

| 章 | 舞台 | 討つ相手 |
| --- | --- | --- |
| 1 灰都の朝 | 灰都ルヴィナ / 旧地下水路 | 暴食のオーガ |
| 2 壊れた城塞 | 宿場ロウ / 崩れの城塞 | 棘鎧の獣王 |
| 3 凍てついた学舎 | 学都アイル / 氷結の学舎 | 氷獄の女王 |
| 4 空を継ぐ塔 | 風の里サイ / 天空回廊 | 天空竜 |
| 5 王都の影 | 王都ヴェルド / 王城地下 | 虚無の王 |
| 6 世界の鏡像 | 最果ての野営地 / 相刻の座 | 世界の鏡像 |

- **町**では宿（パーティ全員全回復）・道具屋・転職の祭壇・装備・スキルツリーが使えます。
  街の声のほかに、仲間どうしの「旅の話」が章ごとに増えていきます。
- **ダンジョン**は数戦ぶんの深さがあり、最奥がその章の主です。
- 章の主を倒すと、その場で**仲間が加わります**（1章＝ミナ、2章＝ガロ、3章＝セラ）。
- **踏破したダンジョンには「残響」が現れます。** 別の主が立っていて、何度でも挑めます。
  道中は無く主に直行、相手は毎回ランダム、挑むほど格が上がります。
  **経験値と金は挑むたびに減りますが（100% → 55% → 30% → 20%で下げ止まり）、
  報酬の3択は毎回そのまま**です。周回する理由を「レベル稼ぎ」ではなく
  「ビルドを進める」側に置くためで、ここを一定にすると、
  周回で稼いだレベルと金で本編を殴り倒せてしまいます。
  残響の主は**育ち具合にも追随する**ので、レベル40で第1章の残響に行っても腕試しになります。
- **全滅しても冒険は終わりません。** 所持金の半分を失い、宿から立て直します。
- **道中の敵は、育ち具合に合わせて格が上がります。** 章の想定レベルを大きく超えて
  育っていると、ダンジョンの雑魚もその分だけ強い個体になります（章の設計値が下限、
  上限は +8 まで）。これをやらないと、レベルだけが先行して中盤が素通りになり、
  最終章だけが壁になります。**章の主は設計どおりの相手のまま**で、
  そこへの上乗せは難易度モードだけが行います。
- 物語を終えたあとは、育てたビルドのまま**試練の塔**へ挑めます。

## パーティ戦闘

戦闘は **主人公＋仲間3人 対 敵** のターン制です。

- **操作するのは主人公だけ。** 仲間は自動で動きますが、行動はでたらめではありません。
  「倒れた仲間がいれば蘇生 → 瀕死の味方を回復 → 主人公が危なければかばう →
  状態異常が溜まっていれば浄化 → 序盤は支援 → それ以外は攻撃」の順に判断するので、
  癒し手・盾役・術師という役割がそのまま盤面に出ます。
- 敵の狙いは**かばう・挑発**を考慮して決まります。
- **主人公が倒れても操作は続きます。** 生き残っているメンバーに手番が移るので、
  そこから蘇生・回復・逃走で立て直せます。
- 全員が倒れると敗北。逃走はボス以外なら可能で、成功率は素早さの差で決まります。
- **長引くと敵が「激昂」** し、以後1ラウンドごとに敵の与ダメージが12%増えます。
  回復量が敵の火力を上回ると勝てないが負けもしない膠着が起きるため、必ず決着がつくようにしています。
  始まるラウンドは難易度で変わります（標準は32ラウンド目から）。
  これは膠着を壊すための仕組みであって難易度の調整弁ではないので、
  **その難易度で最も長い戦い（最終戦）より後ろ**に置いてあります。
- **ボスの追撃。** 高難度以上では、ボスの残りHPが一定を切ると、
  ラウンドの終わりにもう一撃入れてきます（威力5割の単体攻撃のみ・回復には使わない）。
  詳しくは「難易度モード」を参照。

### 仲間

| 名前 | 職 | 役割 | 固有技 |
| --- | --- | --- | --- |
| ミナ | 神官 | 癒し手 | 手当て（回復＋状態異常解除）／守りの祈り（全体バリア） |
| ガロ | 剣士 | 盾役 | 盾となる（かばう）／鼓舞（挑発＋全体攻撃力上昇） |
| セラ | 魔術士 | 術師 | 増幅の術式（与ダメ+40%＋MP譲渡）／魔力吸引（MP0で撃ちMPを奪う） |

### 仲間も転職する（系統制）

仲間も主人公と同じく、**転職・装備・スキルツリー・職業ツリー**を持ちます。
ただし進める先は人物ごとの**系統（line）**で限られます。
誰でも何にでもなれると人物像が崩れるので、その人が選ぶに足る道だけを用意し、
その中で自由に育てる形にしました。

| 仲間 | 系統 | 行き着く先（本人だけの最上級職） |
| --- | --- | --- |
| ミナ | 神官 → 破魔僧 / 守護者 / 吟遊詩人 | **暁光聖母** / **不倒聖盾** |
| ガロ | 剣士 → 守護者 / 狂戦士 | **不動城塞** / **忿怒盾鬼** |
| セラ | 魔術士 → 元素使い / 嵐使い / 呪術師 / 呪縛士 | **万理術理** / **静謐災禍** |

- **解放条件は本人のもの**です。上級職は「その人がどう戦ったか」、
  最上級職は「その人のアクセサリ4枠」で決まります。
  戦い方の記録は行動した本人に付くので、ミナが光と闇で撃てばミナに破魔僧が開きます。
- **固有技（signature）は職業に関わらず常に持ちます。**
  ガロが守護者になっても〈盾となる〉〈鼓舞〉は残ります。
  「職業は変わっても、この人がやることは変わらない」という部分です。
- **装備はパーティ共有の持ち物から各自が選びます。**
  同じ指輪を2人が同時に着けることはできず、選択画面には誰が装備中かが出ます。
- SP・習熟度は全員に同じだけ配られます。財布（ゴールド）は共有です。

#### 仲間だけの最上級職（全6種）

仲間の系統の先端は、**主人公が就けない、その人物専用の最上級職**です。
逆に主人公の11の最上級職には、仲間は就けません。
「主人公は何にでもなれる／仲間は自分にしかなれないものになる」という対比にしています。

| 固有最上級職 | 誰の | アクセサリ4枠に求められる構成 | その職の芯 |
| --- | --- | --- | --- |
| **暁光聖母** | ミナ | 吸収90以上・占有30%以上＋光と闇の両属性50以上 | 過剰回復・蘇生・光の極み。倒れることを許さない |
| **不倒聖盾** | ミナ | 堅守100以上・占有35%以上 | 全体バリアと踏み止まり。前には出ないが後ろで誰も倒れない |
| **不動城塞** | ガロ | 堅守と反射をどちらも60以上 | 防御力がそのまま攻撃力になる（棘＋反撃） |
| **忿怒盾鬼** | ガロ | 吸収と堅守をどちらも55以上 | 瀕死ほど火力が上がる盾役。吸収32%で自力で戻る |
| **万理術理** | セラ | 属性140以上・占有42%以上＋全属性を14%以上 | 全属性同時撃ち・属性循環・二重詠唱 |
| **静謐災禍** | セラ | 範囲と呪詛をどちらも55以上 | 状態異常の伝播と持続。範囲で撒いて枯らす |

いずれもレベル12以上が共通条件で、暁光聖母・万理術理を除く4職はレジェンドアクセサリ1個以上も要ります。

それぞれに専用の奥義があります（暁光聖母〈暁を告げる〉、不倒聖盾〈不倒の誓い〉、
不動城塞〈城塞たれ〉、忿怒盾鬼〈忿怒開門〉、万理術理〈万理を解く〉、静謐災禍〈静かな災い〉）。
解放条件の判定は主人公と同じ仕組みなので、**その仲間のアクセサリ4枠を自分で組む**必要があります。

装備・転職の祭壇・スキルツリーの各画面に、誰のビルドを見るかの切替が付きます。

`node tools/check-ally-lines.js` で、各系統の先端まで実際に到達できるかを機械的に確認できます。

### 旅の話

町では、その章までに加入した仲間どうしのやりとりが読めます（全14件）。
本筋には一切絡まない、道中の会話だけの層です。

戦うたびに近くなっていく距離を、言い切らずに書いています。
言いかけてやめる、第三者が先に気づく、返事が一拍遅れる ―― そういう書き方で、
**カイとガロ**、**ミナとセラ**のあいだにある感情を、断定せずに置いてあります。
受け取り方は読む人に委ねる分量に留めました。

## 敵の強さ（全体の底上げ）

仲間にも職業・装備・スキルツリーを持たせたことで、こちらが強くなりすぎていました。
難易度モードとは別に、**すべての難易度に共通する土台**を引き上げています。

- 雑魚のHPを一律 +30%、火力の伸び方も上げました。短い戦闘では敵が動く前に片付いてしまい、
  火力だけ上げても手応えになりません。**まず殴り合いの回数が要る**、という判断です。
- 精鋭は HP +45%・攻撃 +15%（従来は HP +35% のみ）。
- ボスの基礎値を HP +20%・攻撃 +14%。ただし**最終ボスだけはHPを下げました**。
  もともと2万近い実効HPで20ラウンド超の削り合いになっており、
  難しいというより長いだけの戦いだったためです。
- 敵の自己修復を 130 → 95。削っても戻る展開が、盤面の判断ではなく作業になっていました。
- ダンジョンの雑魚は主人公のレベルに追随します（下限は章の設計値、上限 +8）。
- 4階以降の雑魚の数を 2〜4体 → 3〜5体に。

同じ測り方（エンジンだけを Node で回す）での比較:

| | 変更前 | 変更後（標準） |
| --- | --- | --- |
| 試練の塔の25階到達 | 39/40 | 22/40 |
| 第1章の勝利時 残HP | 78% | 71% |
| 第3章 | 89% | 72% |
| 第4章 | 91% | 84% |
| 第5章 | 86% | 79% |
| 第6章 | 77% | 60% |
| 最終戦のラウンド数 | 8.3 | 14.4 |

第2章だけほとんど動いていません（86% → 85%）。
この章はレベルの伸びが敵の設計値をまだ追い越していないため、追随の余地が小さいからです。
ここを動かすには経験値曲線そのものを変える必要があり、今回は手を付けていません。

## 難易度モード（全4段）

タイトル画面で選び、**冒険の途中でも町（塔なら焚き火）でいつでも変えられます**。
選んだ難易度は保存され、次に始めるときの既定になります。

倍率だけを動かすと「ただ長い戦闘」になって手応えにならないので、
**敵が何体出るか・どこを狙うか・ボスが終盤に何をするか**まで一緒に変えています。

| | やさしい 🌱 | 標準 ⚔ | 高難度 🔥 | 相剋 💀 |
| --- | --- | --- | --- | --- |
| 雑魚のHP / 火力 | -22% / -30% | ±0 | +15% / +10% | +22% / +16% |
| ボスのHP / 火力 | -26% / -30% | ±0 | +6% / +3% | ±0 / -4% |
| 取り巻き・雑魚の数 | 変わらず | 変わらず | +1体 | +1体 |
| ボスの追撃 | なし | なし | 残りHP30%から | 残りHP60%から |
| 敵の狙い | でたらめ | ほぼでたらめ | 4割は脆い者へ | 8割は脆い者へ |
| 激昂の開始 | 36R | 32R | 30R | 28R |
| 経験値・金 | ±0 | ±0 | +18% | +40% |
| レアの出やすさ | ±0 | ±0 | +10% | +20% |
| こちらの被ダメージ | -12% | ±0 | ±0 | ±0 |
| 逃走のしやすさ | +15% | ±0 | -10% | -20% |

### 追撃 ―― 数字ではなく手番で難しくする

高難度以上では、ボスが**残りHPが一定を切ってからラウンドの終わりにもう一撃**入れてきます。
追撃は威力5割の単体攻撃だけで、全体技・状態異常・自己回復には使いません。

- **最初から2回動かせると、戦いが単に倍の長さになるだけ**でした。
  実測で塔の25階到達が 27/40 → 1/40 まで落ち、ビルドの差ではなく事故で決まる戦いになりました。
- 残HPで区切ると「あと少しで倒せる」局面だけが険しくなり、
  そこまでの組み立てが効くようになります。25階到達は 高難度 13/40・相剋 5/40 に落ち着きました。
- 相剋のボス倍率が標準以下なのは、**残HP6割から毎ラウンド追撃する**ぶんを差し引いているためです。
  数字は小さくても、実際に受ける総ダメージは相剋のほうが大きくなります。

### 計測結果

エンジンだけを Node に載せて回した結果です（物語20周・塔80走行、下記の自動テスト）。

| | やさしい | 標準 | 高難度 | 相剋 |
| --- | --- | --- | --- | --- |
| 物語モードの完走 | 20/20 | 20/20 | 20/20 | 20/20 |
| 物語モードの全滅回数（平均） | 0.0 | 0.0〜0.1 | 1.6〜2.6 | 4.7〜5.3 |
| 試練の塔の25階到達（160走行） | 全通 | 88/160 | 45/160 | 46/160 |

物語モードは全滅しても立て直せるので、完走率ではなく**全滅回数**が手応えの指標になります。
塔は一度倒れたら終わりなので、到達率がそのまま難度です。

塔の相剋が以前の 2/40 から上がっているのは、25階の主「世界の鏡像」を
**倒せる相手に作り直したから**です。以前は光・闇・物理を弾いて弱点が無く、
自己回復まで持っていたので、噛み合わないビルドはそこで確実に止まりました。
到達率の低さがボスの出来の悪さで支えられている状態だったので、そこは戻していません。

なお物語モードのシミュレータは町で毎回補充してから潜ります。
補充しないまま測ると実際より厳しい数字が出るためで、
**標準の全滅回数 0.0 は「万全の準備なら事故らない」という意味**です。

## 実装した要素

### 特殊攻撃（全174種）

数値ではなく**仕掛け**で状況を動かす技を軸に据えています。

| 仕掛け | 内容 | 代表的な技 |
| --- | --- | --- |
| 溜め | 次の攻撃の威力を上乗せする | 集中／魔力過装／血の供物 |
| 反撃の構え | 攻撃を受けるたび自動で反撃する | 迎撃の構え／鉄壁反撃／残像 |
| かばう | 味方への単体攻撃を肩代わりする | 庇護の構え／守護陣／盾となる |
| 挑発 | 敵の狙いを自分に集める | 挑発／威圧咆哮／鼓舞 |
| 刻印 | その敵への被ダメージを増やす | 弱点看破／魔紋剣／疫の刻印 |
| 封印 | 敵に技を使わせない | 盾打ち／魔封じ／聖鎖／魂縛 |
| 暗闇 | 敵の攻撃を外れやすくする | 煙玉 |
| 打ち消し | 敵の強化とバリアを剥がす | 解呪波／虚無帰結 |
| 蘇生 | 倒れた仲間を戦線に戻す | 蘇生／最終評決 |
| MP奪取 | 敵から魔力を吸う（MP0で撃てる技も） | 魔力喰らい／掠め取り／魔力吸引 |
| 身代わり | 自分のHPを味方に分け与える | 献身 |
| 連携追撃 | 生存している味方全員が追撃に加わる | 共鳴斬／双極・終焉 |
| 強化 | 味方の数値を上げる（効果量と継続を伸ばせる） | 進軍歌／守りの詩／天佑の凱歌 |
| 弱体 | 敵の数値そのものを下げる | 刃鈍らせ／万象衰え／零落の宣告 |
| 持続ダメージ | 毒・火傷でラウンドごとに削る | 腐蝕の手／瘴気／万象腐蝕 |

最上級職には**奥義が2つずつ**あります。

### 持続ダメージビルド（呪詛）

毒と火傷は「相手の**最大HPの割合**」で削るので、もともとHPの高いボスに強い型でした。
ただし**伸ばす手段が1つも無く**、呪詛軸に効く mod キーがゼロで、
アクセサリ4枠に積める得点も他の軸の半分以下（107 対 200〜450）でした。
疫災呪王の解放条件だけが甘かったのは、そもそも天井が低かったからです。

そこで**呪詛軸に伸ばす手段を用意**し、そのぶん割合部分を落として、
「素で強い」から「**組んだ人が強い**」に置き換えました。

| | 内容 |
| --- | --- |
| 伸ばす指標 | 持続ダメージ `dotPower` ／ 持続の継続 `dotTurns` |
| 上級職 | **疫医** |
| 最上級職 | **万蝕王** |
| 通常アクセ | 毒の小瓶／腐蝕の腕輪 |
| レジェンド | 蝕みの王冠／屍喰らいの顎／万毒の牙 |
| ミシック | 不朽の腐核 |

| フラグ | 効果 |
| --- | --- |
| 化膿 `festering` | 毒と火傷が同時に乗っている敵への持続ダメージ+25% |
| 深蝕 `deepRot` | 自分がかけた毒・火傷は、ラウンドごとに威力が増していく（上限あり） |
| 腐食の宴 `rotFeast` | 持続ダメージで敵を倒すと、最大HPの10%を回復する |
| 疫散 `plagueBurst` | 持続ダメージで敵が倒れると、その毒が周囲の敵へ移る |
| 毒刃 `venomEdge` | 攻撃時、35%で毒を付与する |

**ダメージの決まり方**は、2つの足し算にしてあります。

```
1ラウンドの持続ダメージ ＝ 相手の最大HP × 技ごとの割合 × 0.75   ← 技が決める。ビルドでは動かない
                        ＋ 術者の魔力 × (0.10 + 0.30 × dotPower) ← ここだけが伸びる
```

- **割合部分を伸ばせるようにしなかった理由**: HPの高い相手ほど一方的に強くなり、
  ほかのビルドが相手にならなくなるためです。実際に伸ばして測ったところ、
  ボスの最大HPの172%を1つの技で削ってしまいました。
- **固定部分を足した理由**: 割合だけだと、HPの低い雑魚にはほとんど効きません。
  伸ばした人が雑魚にもボスにも通るように、術者の魔力に比例する分を足しています。
- **割合を0.75に下げたぶん**は、誰にでも乗る固定分（0.10）でほぼ戻しています。
  雑魚に対する持続ダメージは変更前より少し上がり、**ボスに対してだけ約12%下がります**。
  下げ幅はエンジンだけを回して決めました。最初は0.55まで落としたところ、
  塔の25階到達が 24/40 → 18/40 まで落ちました。パーティは炎や毒の持続ダメージを
  思ったより当てにしていて、素の持続ダメージを削ると全体の難度が上がってしまいます。

同じ測り方での前後比較（レベル20・疫災呪王・1ラウンドあたり）:

| | 変更前 | 変更後（素） | 変更後（万蝕王＋専用アクセ4枠） |
| --- | --- | --- | --- |
| 雑魚（魔騎士 812HP）への毒 | 73 | 123 | 333 |
| ボス（虚無の王 5920HP）への毒 | 533 | 468 | 716 |

**雑魚に強くなり、ボスには少し弱くなり、伸ばせば両方に効く**という形です。

### 支援ビルドと弱体ビルド

殴る・受ける以外の勝ち方として、**強化と弱体を伸ばす軸**を用意しました。
どちらも「かける側の性能」で、受け手ではなく術者の数値を見ます。

| | 支援（バフ） | 弱体（デバフ） |
| --- | --- | --- |
| 伸ばす指標 | 強化の効果量 `buffPower` ／ 継続 `buffTurns` | 弱体の効果量 `debuffPower` ／ 継続 `debuffTurns` |
| 上級職 | **吟遊詩人** | **呪縛士** |
| 最上級職 | **天佑楽帝** | **零落呪帝** |
| 共通ツリー | 支援の道 | 弱体の道 |
| 通常アクセ | 詩人の護符／軍旗の徽章 | 呪縛の針／零落の封印 |
| レジェンド | 凱歌の竪琴／暁光の外套／進軍の軍旗 | 衰えの杖／万縛の鎖／削骨の篭手 |
| ミシック | 万象の合唱 | 零落の帳簿 |

支援側の特殊効果:

| フラグ | 効果 |
| --- | --- |
| 唱和 `boonShare` | 自分にかけた強化が、味方全体にも半分の強さでかかる |
| 再演 `encore` | 支援スキルの使用後、30%でもう一度同じ効果が発動する |
| 護歌 `boonGuard` | 強化が1つでも乗っている味方は被ダメージ-14% |
| 号令 `openingRally` | 戦闘開始時、味方全体の物理・魔法攻撃+18%（3ターン） |
| 簒奪 `boonSteal` | 敵の強化を打ち消したとき、その強化を自分が受け取る |

弱体側の特殊効果:

| フラグ | 効果 |
| --- | --- |
| 烙印 `hexBrand` | 弱体が乗っている敵への与ダメージ+30% |
| 伝播 `spreadHex` | 弱体を与えたとき、40%で他の敵にも同じ弱体が広がる |
| 打擲 `sapStrike` | 攻撃時、25%で敵の物理攻撃を20%下げる |
| 積弊 `doomToll` | 敵に乗っている弱体1つにつき、その敵への与ダメージ+8% |
| 侵蝕 `frailtyAura` | ラウンド終了時、弱体が乗っている敵の防御がさらに下がる |

設計上そうしている点:

- **呪詛（状態異常）とは別の軸**にしました。毒や麻痺を撒くことと、
  敵の攻撃力そのものを削ることは、組み方も、相手に効くかどうかも違います。
  状態異常が入りにくいボスにも、弱体は通ります。
- **1ターンだけの構えは伸びません。** 「防御」の被ダメ60%減まで支援ビルドの倍率で
  伸びると、防御を押すだけで硬くなる別のゲームになります。継続2ターン以上の強化だけが対象です。
- **強化技に混じる自分への不利は伸ばしません。** 〈鬨の声〉の被ダメ-10%のような
  代償まで倍率で膨らむと、支援に寄せた人が自分の首を絞めることになります。
- **弱体には下限（-70%）があります。** 重ねがけできるので、これが無いと
  攻撃力が負の値になって計算が壊れます。7割減までは通り、そこから先は何を重ねても効きません。
- 仲間のAIも対応しました。強化を伸ばす装備を着けた仲間は**切れたら掛け直し**、
  弱体を伸ばす装備を着けた仲間は**まだ乗っていない弱体を優先**します。
  威力だけで技を選ぶままだと、素の火力が低い支援・弱体の技は永久に使われません。
- **ミナは吟遊詩人に、セラは呪縛士に**なれます（系統に追加）。
  仲間に支援・弱体を任せて、主人公は殴りに専念する組み方もできます。

同じAIで、装備と職業だけを変えて塔を40回ずつ登らせた結果（難易度 相剋）:

| ビルド | 25階到達 |
| --- | --- |
| 素の剣士（比較用） | 21/40 |
| 会心（絶影剣聖） | 36/40 |
| **支援（天佑楽帝）** | **39/40** |
| **弱体（零落呪帝）** | **40/40** |
| **持続（万蝕王）** | **31/40** |
| 呪詛（疫災呪王・既存） | 38/40 |

弱体が最も安定するのは、**ボスにも確実に通る**からです。
状態異常は耐性で弾かれることがありますが、能力値の低下はどんな相手にも同じだけ効きます。
そのかわり火力そのものは伸びないので、削り切る手段は別に用意する必要があります。

### 1. 多岐にわたるビルド（アクセサリ4枠）

装備スロットは **武器 / 防具 / アクセサリ×4**。
アクセサリ4枠の組み方がビルドの本体で、以下の軸を自由に伸ばせます。

| 軸 | 主な指標 | 代表的な挙動 |
| --- | --- | --- |
| 会心 | 会心率 / 会心ダメージ | 会心時に防御無視、多段攻撃との相乗 |
| 反射 | 反射率 / 反射威力 | 被弾ダメージを跳ね返す。全体化・反射回復あり |
| 範囲 | 波及率 / 範囲威力 | **単体攻撃が他の敵にも波及**する。全体技の威力増 |
| 属性 | 炎・氷・雷・風・光・闇の各ダメージ / 耐性貫通 | 弱点1.6倍、耐性0.55倍を貫通で緩和 |
| アイテム | アイテム威力 / 温存率 | 消耗品が主力火力になる。温存率で消費しない |
| 吸収・堅守 | 吸収 / 被ダメ軽減 / 回避 / バリア | 殴られながら勝つ構成 |

さらに **特殊効果（フラグ）が44種類**あり、数値では表せない挙動を足します。

- 反射の全体化 / 反射ダメージの一部をHPに変換 / ラウンド終了時の棘ダメージ
- 通常攻撃の2分割 / 通常攻撃の全属性化 / 通常攻撃の属性が毎ターン移り変わる
- 会心時に防御無視 / 会心時に追撃 / 各戦闘の初撃が必ず会心
- 素早さや物理防御の一部を攻撃力に変換 / 残りMPの割合で与ダメージ上昇
- 敵が3体以上／1体のみ／瀕死／ボス／状態異常中 のときに与ダメージ上昇
- 魔法スキルの二重詠唱 / 状態異常の周囲への伝播 / 回避時の反撃
- 致死ダメージ耐え / HP50%以下で被ダメ減 / 回復の超過分がバリアになる
- 撃破時にHP回復・MP回復・攻撃力累積・周囲へ爆散
- アイテム効果の再発動 / 戦闘開始時のアイテム補充・バリア展開

### 2. 職業は「戦い方」と「組み方」で解放される

職業は **初級職(4) → 上級職(14) → 最上級職(15)** の3段階、全33種。
これに**仲間の固有最上級職が6種**と**隠し職業1種**が加わり、実装は全40種です（後述）。
解放条件が2つの段で**別種の証拠**になっているのが、この作品の骨格です。

| 段 | 何を見るか | 意味 |
| --- | --- | --- |
| **上級職** | **どう戦ったか**（行動の実績） | 実際にその戦い方をしていれば自動的に解放される |
| **最上級職** | **どう組んだか**（アクセサリ4枠の構成） | 装備の構成そのものが条件になる |

#### 上級職 ―― 戦闘スタイルで自動解放

戦闘中の行動を11軸で記録します
（会心・反射・範囲・属性・アイテム・吸収・堅守・速攻・呪詛・**支援**・**弱体**）。
軸ごとに発生頻度が違うため、**1ラウンドにつき各軸1回まで**に正規化してから比率を取ります。
これをやらないと、範囲のような高頻度の軸が常に勝ってしまい、アイテムや呪詛の戦い方が
永久に評価されません。また敵の手番はプレイヤーより多いため、手番単位で数えると
堅守・反射が構造的に膨らみます。

| 上級職 | 解放される戦い方 |
| --- | --- |
| 暗殺者 | 会心を多く出して戦った |
| 守護者 | 反射または堅守で受け止めて戦った |
| 嵐使い | 範囲攻撃を主軸に戦った |
| 元素使い | 属性ダメージを主軸に戦った |
| 錬金術士 | アイテムを多用して戦った |
| 狂戦士 | 吸収で回復しながら戦った |
| 韋駄天 | 回避を多用して戦った |
| 呪術師 | 状態異常を撒いて戦った |
| **吟遊詩人** | **味方に強化を掛けて戦った** |
| **呪縛士** | **敵の能力値を下げて戦った** |
| **疫医** | **状態異常を撒いて戦った（呪術師より深く）** |
| 破魔僧 | 光と闇の両方でダメージを与えた |
| 魔剣士 | 物理と魔法の両方でダメージを与えた |

条件を満たすと自動的に候補に入り、「転職の祭壇」で**選んで**転職します。
複数の職が同時に解放されることもあり、そこが選択になります。

#### 報酬の3択は、軸を散らして出す

精鋭とボスに勝つと、アクセサリ3つから1つを選びます。ここが**ビルドの方向を決める場所**です。

ただ抽選すると、母数の多い軸ばかりが並びます。実測では、3択に自分の軸が入る確率が
**属性70%に対してアイテム12%**、そのうえ**27%は3つのうち2つが同じ軸**で、選択が成立していませんでした。
「良いものが出る」ことと「ビルドが偏らない」ことを両立させるため、3つの軸を意図的に散らします。

| 枠 | 何が出るか | 役割 |
| --- | --- | --- |
| 1つ目 | **今のビルドの主軸** | 深める選択肢。必ず使えるものが出る |
| 2つ目 | **まだ薄い軸** | 乗り換える選択肢。これが無いと一本道になる |
| 3つ目 | 残りの軸からランダム | 意外性 |

- **押しつけないことが目的**なので、2つ目の「乗り換え枠」は毎回必ず入ります。
  良いものを配るだけだと、最初に出た軸で残りが決まってしまいます。
- **始めたばかりのうちは主軸なし**として扱い、3つとも別々の軸から選びます。
  初期装備の幸運のコイン（会心率+5%）だけで「会心ビルド」と見なされると、
  1回目の報酬から会心へ誘導してしまうためです。
- 直した結果、**3つとも別の軸になる率が 60% → 100%**、重複は 27% → 0%。
  自分の軸は必ず出るようになり、残り2枠は11軸に均等（各16〜25%）に散ります。

#### 最上級職 ―― アクセサリ構成で解放

装備中の**アクセサリ4枠だけ**を見て、同じ11軸で構成の性格を採点します。
mod（会心率、反射率、属性ダメージ…）と特殊効果フラグの両方が加点対象です。

| 最上級職 | アクセサリ4枠に求められる構成 |
| --- | --- |
| 絶影剣聖 | 会心構成（得点110以上・占有45%以上） |
| 鏡獄天帝 | 反射構成（120以上・40%以上） |
| 天災嵐王 | 範囲構成（130以上・40%以上） |
| 星辰術皇 | 属性構成（150以上・45%以上） |
| 万象錬成王 | アイテム構成（150以上・45%以上） |
| 血喰鬼神 | 吸収構成（90以上・35%以上） |
| 神速天翔 | 速攻構成（130以上・40%以上） |
| 疫災呪王 | 呪詛構成（110以上・35%以上） |
| **万蝕王** | **呪詛構成（130以上・40%以上）** |
| **天佑楽帝** | **支援構成（130以上・40%以上）** |
| **零落呪帝** | **弱体構成（130以上・40%以上）** |
| 終焉審判者 | 光＋闇の強化が70以上 |
| 双極魔剣皇 | 会心と属性を両立（各60以上） |

いずれもレベルとレジェンドアクセサリ1個以上が追加条件です。
**13職すべてが、ミシック無し（レジェンドまで）で到達可能**であることを、
`node tools/check-classes.js` で機械的に確認しています
（職業の解放条件をそのまま読んで、それを満たす4枠を組んで判定します）。

現在の戦い方とアクセ構成は、マップ画面と転職の祭壇に常時表示されます。

### 3. スキルツリー（共通11系統＋職業限定の奥義）

**SP（スキルポイント）** を振って伸ばす、全職業共通のツリーです。
**66ノード＝11系統×6ノード**。ここで伸ばした数値はそのまま職業の解放条件に反映されるので、
「装備だけでは届かない閾値をSPで越える」という選択が生まれます。

| 系統 | 伸びるもの | 頂点で習得するスキル |
| --- | --- | --- |
| 会心の道 | 会心率・会心ダメージ、瀕死特効、会心追撃 | 断罪の型 |
| 反射の道 | 反射率・反射威力、棘のオーラ | 返報の誓い |
| 範囲の道 | 波及率・範囲威力、撃破の連鎖、多数戦特効 | 拡散連撃 |
| 属性の道 | 全属性ダメージ・耐性貫通、弱点特効、属性循環 | 属性転変 |
| アイテムの道 | アイテム威力・温存率、開幕バリア、効果の再発動 | 即席調合 |
| 堅守の道 | HP・防御・被ダメ軽減、背水、全属性軽減 | 不動明王 |
| 速攻の道 | 素早さ・回避、初撃確定会心、回避時の反撃 | 残影 |
| 生命の道 | 最大HP・吸収、撃破時回復、回復超過分のバリア化 | 生命線 |
| 呪詛の道 | 持続ダメージの威力・継続、状態異常の延長・伝染・特効 | 呪いの華 |
| **支援の道** | **強化の効果量・継続、加護の全体化、再演** | 鼓舞の讃歌 |
| **弱体の道** | **弱体の効果量・継続、伝播、殴打での弱体付与** | 解体の呪 |

- 構造は 入口(1SP)×2 → 発展(2SP)×2 → 頂点(3SP) → **奥義(3SP)**。
- 11系統はそれぞれ対応する上級職・最上級職を持ちます（速攻→韋駄天／神速天翔、
  呪詛→呪術師／疫災呪王、支援→吟遊詩人／天佑楽帝 など）。
- **奥義ノードは職業限定**です（例: 反射の「鏡獄の理」は守護者／鏡獄天帝のみ）。
  共通ツリーでありながら、職業を選んだ意味が最後に効いてきます。
- SPは **レベルアップ+1／精鋭撃破+1／ボス撃破+2**。ゲーム開始時に2SP。
- **振り直しはゴールドを払えばいつでも可能**（60 + 使用SP×25 G）。
  ミシックの特殊条件を狙うための一時的な組み換えにも使えます。

### 4. 職業ツリー（同じ職業の中で差分化する）

共通ツリーとは別に、**40職すべてに専用の分岐ツリー**があります。
**3段 × 2択（排他）** なので、同じ職業でも **2⁸ ではなく 2³ = 8通り** に分かれます。
40職 × 8 = 320通りの「同じ職業だが別物」が作れます。

- 解放は **習熟度**（その職業で戦った回数）。通常戦闘+1／精鋭+2／ボス+3。
  実測では、塔なら**6階あたりで最終段（習熟9）が開きます**。
  第1段は習熟2、第2段は5、第3段は9で開きます。
- **各段は片方しか選べません。** 選ばなかった側は「選ばなかった道」として残ります。
- 第3段の多くは**スキルを1つ習得**します。同じ職業でも手札が変わります。
- **効果が有効なのは今就いている職業の選択だけ**です。転職すると休眠しますが、
  記録は残るのでその職業に戻れば復活します（習熟度も職業ごとに別々に蓄積）。
- 選び直しはゴールド（120 + 選択数×90 G）。

例（剣士）:

| 段 | 選択肢A | 選択肢B |
| --- | --- | --- |
| 1 | 剛剣: 物理攻撃+12% | 堅陣: 物理防御+18%／被ダメ-5% |
| 2 | 連撃: 通常攻撃が2回に分裂 | 必殺: 会心率+10%／会心ダメ+30% |
| 3 | 疾駆: 素早さ+20／波及+15%・〈旋風斬〉習得 | 不屈: 最大HP+15%／致死耐え・〈挑発〉習得 |

「共通ツリー＝どのビルドを目指すか」「職業ツリー＝その職業をどう解釈するか」
という二層構造になっています。

### 5. アクセサリは3階級

**全160種**あります。

- **通常（81種）** … 素直な数値強化。単一軸の強化、6属性の宝珠・輝石、
  会心×反射のような二軸ハイブリッドまで揃い、ビルドの土台になります。
- **レジェンド（52種）** … クセの強い特殊効果つき。デメリット持ちも多い。
  （例:「断罪者の血盟」会心率+25%・会心ダメ+65%だが最大HP-18%、
  「一騎討ちの証」敵が1体のときのみ与ダメージ+40%）
- **ミシック（27種）** … **戦闘中／冒険中の特殊条件を満たすと「発見」** される最強級。
  一度発見すれば**記録に永続保存**され、以後の冒険でも行商人から入手可能になります。

## 立ち絵（すべてコード生成）

会話と人物表示用に、**48×84ドットの立ち絵**を手続き生成しています。こちらも画像ファイルは0枚です。

- 体型（細身／標準／重装）・髪型6種・装い（法衣／軽装／重装）・マント・得物5種を
  **部品として重ね合わせ**、最後に輪郭を1px巻いて描いています。
  輪郭があるので、どんな背景色の上でもシルエットが立ちます。
- 顔は白目・瞳・上まぶた・眉・鼻・口を別々に置いており、眉の高さで表情が変わります。
- 主人公の立ち絵は**今の職業の装いになります**。25職すべてに色・得物・マント・髪型の
  組み合わせを用意してあるので、転職すると見た目が変わります。
- 会話中は**直近に喋った二人**を並べ、話していない側を沈ませます。掛け合いが追いやすくなります。

### アニメ調（SVG）とドット絵

会話の顔だけは、ドット絵のほかに**アニメ調のベクター（SVG）**でも描けます。
既定はアニメ調で、図鑑の「人物」から切り替えられます（設定は保存されます）。

ドット絵は輪郭が階段状になるため、目や口のような小さく繊細な形が苦手です。
ベクターなら曲線が使えるので、同じ設定から別の絵柄を起こせます。

- **線に入り抜きがあります。** SVGの `stroke` は太さを変えられないので、
  曲線を標本化して法線方向に太さぶん膨らませ、閉じた図形として塗っています（`ink`）。
  始点を細く、途中で太らせ、抜きで細くする。これが「図形」と「線画」を分けます。
- **真正面をやめています。** 左右対称は人が描いた絵にはまず無いので、顔をわずかに振り、
  遠い側の頬を圧縮し、目の大きさと間隔を左右で変え、耳は近い側だけ描いています。
- 髪は「滑らかな塊」ではなく**尖った房の集合**。房ごとに明・中・暗を振り分け、
  合わせ目に入り抜きの線を入れ、内側に束の線を5本走らせています。
- 目は白目・虹彩（上が暗く下が明るい縦グラデーション）・瞳・光点2つ・
  太い上まつ毛・目尻のはね・二重の線・細い下まぶたの層。
- 影はセル塗り1段（近い側の頬と前髪の落ち影）。光源は左上で固定です。
- 体型・髪型・色・得物は**ドット絵とまったく同じ設定**（`js/data/faces.js`）から
  読んでいるので、絵柄を切り替えても同じ人物になります。

**この方法の限界について。** ここでやっているのはベジエ曲線の制御点を数値で置く作業です。
線の揺らぎ、崩し、思い切った省略といった「絵の良し悪しを決めている要素」は入りません。
どれだけ手を入れても、よくできたベクター画止まりで、人が描いた絵にはなりません。
本格的な絵が要る場合は、`docs/portrait-prompts.md` のプロンプトで生成するか描き起こし、
`assets/portraits/` に置いて差し替えてください（そちらが優先して表示されます）。

会話の顔は「用意した画像 → アニメ調 → ドット絵」の順に落ちます。

### 全身とバストアップの2種類

全身（48×84）では顔に16pxしか割けず、人物の見分けがつきません。
そこで会話用に**バストアップ（52×60）**を別に組み、同じ画素数を胸から上だけに注いでいます。

顔の割付は頭の中心から決めています（眉＝中心-5／目＝中心／鼻先＝+7／口＝+11／顎＝+17）。
片目6px・両目の間隔6pxで、顔幅30pxに対して自然な比率になります。
目は白目・虹彩・瞳・光点・上まつ毛・下まぶたの6層で、眉尻の上下だけで表情が変わります。

| 用途 | 使うもの |
| --- | --- |
| 会話画面 | アニメ調SVG（既定）／ドット絵バストアップ（切替可） |
| パーティ一覧・転職の祭壇・職業選択・図鑑 | 全身（装備と体格が分かる） |
| 戦闘中 | 16×16スプライト（情報量を優先） |

### 描いた絵への差し替え

用意した画像があれば、人物ごとに差し替えられます。

1. 画像を `assets/portraits/` に置く
2. `js/data/portrait-assets.js` に1行足す

```js
G.PORTRAIT_ASSETS = {
  garo: { bust: 'assets/portraits/garo_bust.png', full: 'assets/portraits/garo_full.png' },
};
```

起動時に実在を確かめ、見つかった人物だけ画像に切り替わります。
**パスが間違っていても画像が無くても、黙って手続き生成に戻る**ので、
一部だけ差し替えた状態でも破綻しません。`bust` だけ／`full` だけの指定も可能です。

生成AIに渡すためのプロンプトは、外見設定から機械的に書き出せます。

```bash
node tools/portrait-prompts.js > docs/portrait-prompts.md
```

`js/data/faces.js` の体型・髪型・色相・得物・年齢を文章化し、
**ゲーム内で実際に使っているHSLをHEXに直して埋め込む**ので、
生成した絵と手続き生成の絵を混ぜてもパレットが揃います。
サイズと置き方は `assets/portraits/README.md` にまとめてあります。

## グラフィック（すべてコード生成・画像ファイル0枚）

外部アセットを一切持たず、**16×16のドットマップ + HSLパレット**から Canvas で描画し、
dataURL としてキャッシュしています。

- **スプライト20種のアーキタイプ**（粘体・蝙蝠・小型人型・大型人型・骸骨・法衣・鳥・樹木・
  亡霊・岩石・甲冑騎士・四足獣・竜・天使・光球・虚無・蠍・結晶・軽装・重装）を
  敵26種と職業19種に割り当て、色相と瞳・アクセント色で個体を作り分けます。
- ドットマップは**左半分8列だけを記述し右半分は鏡像**として展開します。
  幅が常に16に揃い、生物的な左右対称のシルエットになります。
- 最上級職には**冠のオーバーレイ**が載ります。
- 装備アイコン（剣・鎧・指輪・薬瓶）とマップのノードアイコン（剣・髑髏・宝箱・
  行商の袋・焚き火・鳥居・星・王冠）も同じ仕組みで生成しています。
  属性強化を持つアクセサリは**宝石の色がその属性の色相**になります。

演出は「読みやすさ優先」で控えめに統一しました。

- ダメージ数字のポップアップ（会心は金・反射は紫・範囲は緑・回復は緑・回避はMISS）
- 被弾時のフラッシュ、攻撃時の踏み込み、撃破時の沈み込み
- 待機時のごく浅い上下動（`prefers-reduced-motion` を尊重して自動停止）
- 階層帯ごとの背景（苔むした坑道 → 凍てつく回廊 → 燃える大聖堂 → 星のない深層 → 深淵）

## 遊び方

**まずタイトル画面で難易度を選びます**（4段・後述）。迷ったら「標準」。
物語を読み進めたいだけなら「やさしい」、一度クリアしているなら「高難度」以上。
**冒険の途中でも町（塔なら焚き火）でいつでも変えられます。**

### 物語モード

1. 主人公の名前を決めて旅に出る（職は剣士から。転職の祭壇でいくらでも変えられる）。
2. 章ごとの地図から**町**か**ダンジョン**を選ぶ。町で支度を整えてから潜るのが基本。
3. ダンジョンは数戦進むと最奥の主に届く。倒せばその章は終わり、次の章へ。
4. 戦闘は速度順のターン制。敵をクリックで対象変更、味方をクリックで回復・支援の対象変更。
   属性の弱点(1.6倍)・耐性(0.55倍)、会心、反射、波及がすべて同じ計算式に乗る。
5. 全滅しても所持金の半分を失うだけ。装備やツリーを組み替えて挑み直せる。

### 試練の塔

1. 初級職（剣士・魔術士・盗賊・神官）を1つ選ぶ。
2. 各階層で **戦闘 / 精鋭 / 宝物庫 / 行商人 / 焚き火 / 転職の祭壇 / イベント** から1つを選んで進む。
3. 精鋭・ボス・宝物庫では**3択の報酬**から1つを選ぶ ―― ここでビルドの方向を決める。
4. 5階ごとにボス。**25階の「世界の鏡像」を倒せば踏破**、その先は無限の「深淵」。
5. 倒れるとそこで終了。ただし発見したミシックと到達した職業の記録は残る。

### バランス設計メモ

敵は「適正階層」からの差分でスケールします（`HOME_FLOOR`）。
上位ティアの敵が初登場した瞬間に数値が跳ね上がらないため、
階層が進むほど一方的に不利になることがありません。

物語モードのダンジョンは、この「階層」を章ごとの設計値で指定します。
つまり塔と物語で戦闘の計算は完全に共通で、違うのは**どの強さの敵といつ戦うか**だけです。

ただし道中だけは、主人公のレベルに追随して階層を引き上げます
（`Story.effLv`、下限は章の設計値）。レベルの伸びが章の想定を追い越すため、
これをやらないと第2〜5章がほぼ無傷で抜けられ、最終章だけが壁になります。

**追随には上限を二つ置いています。**
一つは章の設計値からの上げ幅（難易度ごとに +5〜+12）。
もう一つが効きます ―― **道中はその章の主を追い越せない**（`bossLv - 1` で止める）。
これが無いと、道中一戦の総HPが主より多くなります。実測では最終章の道中が
主の 1.2 倍のHPを抱えていて、17ラウンドかかる「ただ長いだけの雑魚戦」になっていました。
上位ティアの敵は一体あたりのHPが跳ね上がるので、後半は**出る数もむしろ絞ります**
（精鋭は最大3体）。数を足すと、難しくなるのではなく長くなるだけです。

難易度モードは `js/data/difficulty.js` にデータとして置き、`G.Diff.get()` を
戦闘エンジン・遭遇生成・報酬抽選から読んでいます。倍率を1か所にまとめてあるので、
数値の調整でエンジンのコードを触る必要がありません。

倍率のほかに、**世界がこちらの育ちにどこまで付いてくるか**も難易度で変えています
（`track` / `trackCap` / `bossTrack`）。倍率だけを上げる難易度は、
詰まったぶん余分に稼いだレベルで薄まってしまい、
「高難度を選んでも標準と同じ手応えで、戦闘が長いだけ」になります。
稼げば楽になる余地はやさしい側に厚く残し、上の難度では世界が追ってきます。
ただし**追随を強くしすぎると詰み**ます。一度 hard/brutal で追随を強めたところ、
第5章で全滅118回の無限ループになりました（負けても敵が下がらないため）。
いまの値は「歯応えは出るが、稼げば必ず抜けられる」ところで止めてあります。

### 召喚 ―― 場に味方を増やす

**召喚士（上級職）→ 万霊統王（最上級職）** の系統を足しました。
呼んだものは**自分で動いて殴り、数ターンで消えます**。
手番をひとつ増やすのと同じことをする、という考え方の職業です。

| | 中身 |
| --- | --- |
| 召喚士 | 解放: 戦い方が「属性」と「支援」の両方に寄る（各14以上）／Lv6<br>精霊招来（炎・3T）・守護獣招来（硬い・4T） |
| 万霊統王 | 解放: アクセ4枠で「支援」と「属性」を両立（各60以上）／レジェンド1個／Lv12<br>【奥義】万霊招来（**2体同時**・5T）・雷光招来ほか |

**呼ぶものの強さは術者の魔力（か攻撃力の高いほう）から決まります。**
術者を伸ばせば呼ぶものも一緒に伸びるので、召喚だけが取り残されません。
同時に出せる数は技ごとの `cap` で縛り、溢れたぶんは古いものから還ります。
パーティ全体への強化は召喚体にも乗るので、**支援ビルドと噛み合います**。

実装で気をつけたところ:

**全滅判定は「本物の仲間」だけで見ます**（`Battle.aliveRealParty`）。
全員倒れて召喚体だけが残った盤面を「まだ負けていない」にすると、
呼び直すだけで延々と粘れてしまいます。

**能力値の組み立ては「側」ではなく「素性を持つか」で分けます。**
`refresh()` は味方なら `hero` から組み立てていましたが、召喚体は `hero` を持ちません。
`u.side === 'player' && u.hero` に変えて、素性の無いものは敵と同じ `base` から組みます。

戦闘画面も同様で、味方欄が `m.hero.level` を直接読んでいたため
召喚体を出した瞬間に画面が落ちていました（実機で検出）。
いまはレベルと職業の代わりに**残りターン**を出し、MP欄は出しません。

#### 隠し職業〈フェンリル〉

30階の本体を倒すと、**フェンリルの着ぐるみ**（ミシック）を持ち帰れます。
これを装備すると、隠し職業**〈フェンリル〉**に就けます。

|  | 中身 |
| --- | --- |
| 入手 | 解き放たれたフェンリル（塔30階）を倒す |
| 条件 | 着ぐるみを装備している ／ レベル20以上 |
| 前提職 | 狂戦士・暗殺者・韋駄天・剣士・盗賊 |
| 中身 | 物攻+34% 速+34 会心+18% 会心ダメ+60% 吸収+22% 最大HP+15%<br>撃破で回復／撃破ごとに攻撃+6%／会心が防御を50%貫通／瀕死で与ダメ+60% |
| 固有技 | 【奥義】顎・ラグナロク ／ 喰らいつき ／ 遠吠え |

**隠し方が他の職業と違います。** ほかの最上級職は一覧に最初から並び、
条件を満たすと解放されます（何になれるかは最初から見えている）。
〈フェンリル〉は `hidden: true` で、**鍵のミシックを見つけるまで存在自体が伏せてあり**、
祭壇にも図鑑にも「到達しうる最上級職」の数にも出てきません。

手がかりは図鑑のミシック側にあります。未発見のミシックは
`??????? 【取得条件】解き放たれたフェンリル（塔30階）を倒す` と表示されるので、
「何かある」ことと「どこへ行けばいいか」だけは分かる、という形です。

**5階と30階は同じ狼の、別の姿です。** 5階で相手にするのは
グレイプニルに縫い止められた**封印体**で、狼そのものではありません。
縛めがあるぶん弱く、削ると緩んで中身が少しだけ顔を出します。
**縛めを噛み切った本体は30階**、ラグナロクの側で待っています。
こちらは開幕から本気で、縛めの代わりに顎を使ってきます。

顎に咥えられた仲間は動けず、敵からも狙われません。放っておいても数ターンで放されますが、
**大きな一撃（本体の最大HPの4%）を叩き込めば、顎をこじ開けて引き剥がせます** ――
ヴィーザルが狼の顎を裂いた、あれです。実測で21回の捕食のうち6回はこじ開けで解けており、
「待つ」と「こじ開ける」のどちらを取るかが選べる形になっています。

雑魚は12種（ドラウグル・ラタトスク・フリムスルス・エインヘリャル・ヴァルキュリア・
ヨトゥン・ガルム・スルトの焔衛・ヴァフスルーズニルほか）。

**アクセサリも塔専用の北欧セットです**（46種・うちレジェンド26種、ミシック1種）。
ミョルニル、グングニル、グレイプニル、ブリーシンガメン、ドラウプニル、
イズンの林檎、スレイプニルの蹄鉄、アンドヴァラナウト、ギャラルホルン、
セーフリームニルの肉、オーズレリルの蜜酒 ―― といった顔ぶれです。

#### 世界を分けるときに気をつけたこと

**片側だけで全職業に到達できること。** 転職の条件は「4枠の合計」で見るので、
軸あたり一枚しか無いと、どれだけ強い一枚でも合計が届きません。
最初に組んだときは**8職が塔から到達不可**になりました。
いまは11の軸すべてについて、レジェンド2枚＋上位の通常1枚が揃っています。
`node tools/check-classes.js --realm norse` で、塔のアクセサリだけで
40職すべてに就けることを確かめられます（`--realm mid` なら物語側）。

**全体攻撃の比率。** 北欧側は当初 27%（相刻は 11%）で、
とくに「スルトの焔衛」が全体攻撃しか持っていませんでした。
6階の精鋭として出たときに事故を量産し、**その一戦だけで60走行中16回の全滅**。
いまは 20% に収め、精鋭がひとつ上のティアから引き始める階も 6階 → 9階に遅らせました。

**残響に北欧が混じらないこと。** 踏破した場所に現れる主は `G.BOSSES` から選ぶので、
そのままだと物語にフェンリルが出てきます。世界で絞ってあります。

### ボスの仕掛け ―― 主ごとに戦い方を変えさせる

ボスが「HPと攻撃力が大きいだけの雑魚」になるのを避けるための層です
（`js/core/gimmick.js`）。数値をいくら盛っても、やることが同じなら手応えは増えず、
戦闘が伸びるだけになります。7体すべてに、戦い方そのものを変えさせる仕掛けを持たせました。

敵データに `gimmick: { kind: '...', ... }` と書くと、この層が解釈します。
エンジンから呼ばれる口は3つだけ（`onStart` / `onRound` / `onDeath`）。

| 章 | 主 | 仕掛け | 何をしてくるか | 崩し方 |
| --- | --- | --- | --- | --- |
| 1章 | 暴食のオーガ | `devour` | 残りHP6割から、取り巻きを喰らって回復し力を増す | 雑魚を先に片付ける |
| 2章 | 棘鎧の獣王 | `shell` | 棘鎧を纏い、剥がすまで刃が半分しか通らない。5ラウンドで閉じ直す | **術なら倍の速さで剥がせる** |
| 3章 | 氷獄の女王 | `summon` | 2ラウンドごとに氷像を呼ぶ（最大2体） | 範囲技で薙ぐか、本体を速く落とす |
| 4章 | 天空竜 | `aloft` | 3ラウンドごとに舞い上がる。**空にいるあいだ物理が届かない**。降りぎわに全体攻撃 | 属性を乗せた一撃か術なら空にも届く |
| 5章 | 虚無の王 | `siphon` | 3ラウンドごとに、一番効いている加護をひとつ吸い取る。加護が無ければMPを奪う | 掛け直す間合いを計るか、吸われる前に決める |
| 6章 | 鏡写しの衛士 | `clones` | **写し身3体を並べ、倒しても4ラウンドで甦る** | **本体を落とせば写し身も崩れる** |
| 6章 | 世界の鏡像 | `phases` | 残りHPで弱点と耐性が4段に入れ替わる | 通る手段が回ってくる |

**どの仕掛けにも必ず崩し方を用意してあります。** 崩し方の無い仕掛けは、
噛み合わないビルドにとってただの壁になるためです。
`node tools/check-bossgimmick.js` が、7体すべてについて
「仕掛けが実際に働いたか」と「**会心（物理一本）と術（属性）の両方で勝てるか**」を確かめます。
一方の軸でしか勝てない主が出たら失敗にします。

調整で分かったことを2つ残しておきます。

**仕掛けと取り巻きを二重に乗せない。** 写し身と、難易度による取り巻きの上乗せが
重なった結果、鏡写しの衛士の一戦が **31ラウンド**になりました。難しくなったのではなく、
ただ長くなっただけです。いまは自分で頭数を増やす主（`clones`/`summon`）には
最初の取り巻きを付けません。本体のHPも写し身のぶん落としてあります（1210 → 880）。

**「全部奪う」は壁になる。** 虚無の王の吸魂は当初こちらの強化を根こそぎ剥がす形で、
支援を積むビルドが立ち行かず、**第5章だけで全滅751回**という数字が出ました。
一番効いている一枚だけを持っていく形にすると、「掛け直す手番を取られる」痛みは
残したまま戦いが成立します。加護を積まないビルドには何も起きなくなるので、
その場合はMPを奪う ―― 虚無らしく、常に何かは持っていきます。

仕掛けを足したぶん全体が重くなったので、経験値の絞り（`xpCatch`）を
高難度 1.00→0.60、相剋 0.50→0.30 に緩めて釣り合いを取ってあります。

### 育ちすぎを抑える（物語モードだけ）

難易度を上げても手応えが変わらない、という問題がありました。原因は**レベルです**。
実測で、パーティは**敵の1.5〜2.3倍のレベル**で各章に着いていました。
章ごとに設計した相手の格が、ほぼ飾りになっていたということです。

しかも `rw`（報酬倍率）が経験値と金の両方に掛かっていたので、
**上の難度ほど速く育つ**（相剋は標準より12レベル高く終わっていた）。
難しくしたぶんを、レベルで払い戻していたわけです。

最初は経験値と金を分けて、上の難度の経験値を削りました。**塔が壊れました**
（標準の25階到達が 18/40 → 2/40）。塔は「登った高さ＝レベル」なので、
経験値を削るとそのまま登れなくなります。物語と塔で、経験値の意味がまるで違う。

そこで**物語モードにだけ効く絞り**を入れました（`Run.storyExpScale`）。

* 相手の格より **+6 レベル**までは満額
* そこから1レベルごとに **4%** ずつ減り、**60%** で下げ止まる
* **遅れているあいだは必ず満額**。詰まったときに稼いで立て直す道は塞がない

絞りの強さは難易度ごとに変えています（`xpCatch`）。
上の難度では弱めます。あちらは**全滅して稼ぎ直すことが立て直しの手段**なので、
同じ強さで絞ると詰みます（相剋は完走 20/20 → 9/20 になりました）。

立て直しの道が本当に生きているかは、残響で確かめてあります。
残響の主はこちらのレベルに追随して出てくる（Lv49 のとき相手は Lv34〜38）ので、
絞りはほとんど効かず、1回目は満額に近い経験値が入ります。

あわせて**標準にもボスの追撃**を入れました（残りHP2割から、ラウンドの終わりにもう一撃）。
数字を上げるより、手番を増やすほうが「終盤だけ畳みかけてくる」形になります。

| | やさしい | 標準 | 高難度 | 相剋 |
| --- | --- | --- | --- | --- |
| 物語の全滅回数（前） | 0.0 | 0.0 | 0.0 | 1.4 |
| 物語の全滅回数（後） | 0.0 | 0.0〜0.1 | 1.6〜2.6 | 4.7〜5.3 |
| 最終レベル（前→後） | 49→45 | 48→45 | 55→52 | 60→58 |
| 塔の25階到達（前→後） | 全通 | 55%→38% | 37%→28% | 21%→18% |

完走はどの難易度でも 20/20 を保っています。

**標準は、準備して丁寧に戦えば今も滅多に全滅しません。**
そこは残してあります（標準で事故死する作りにはしたくないため）。
標準で変わったのは、余裕の幅とボスの追撃、そして塔の踏破率です。
はっきり負けたい人は高難度以上へ、という切り分けにしています。

なお敵の倍率（`ehp`/`edf`）は**塔の踏破率で較正してあり、物語側の都合で動かしません**。
塔は敵の硬さがそのまま壁になるモードで、`ehp` を 1.22 → 1.12、`edf` を 1.12 → 1.04 に
下げただけで、相剋の25階到達が 3/40 → 16/40 に跳ねました。
物語が長すぎる・短すぎるときは、倍率ではなく**章のデータ側**（設計レベル・敵の構成）で直します。

### 章ごとの手応え（のこぎり波と最終章の崖を潰す）

`node tools/pacing.js` で章ごとの手応えを測れます。作り始めの実測はこうでした ――

| 章 | 1章 | 2章 | 3章 | 4章 | 5章 | 6章 |
| --- | --- | --- | --- | --- | --- | --- |
| 勝利時の残HP | 62% | **85%** | 73% | **85%** | 79% | 59% |
| 主戦の残HP | 33% | 58% | **81%** | **77%** | 66% | 51% |
| ラウンド | 3.7 | 3.3 | 5.2 | 3.8 | 6.9 | **13.9** |
| 全滅 | 0 | 0 | 0 | 0 | 0 | **7** |

2章と4章がへこみ、最終章だけが崖。**人が離れるのはこの形**です。
原因は三つありました。

1. **章の設計レベルが、レベルの伸びに追いついていなかった。**
   第4章は想定 Lv13 に対してこちらが Lv17〜25。敵の構成も下位ティアが半分。
   → 章ごとの設計レベルを、道中→主→次の章の道中、と単調に並べ直しました。
2. **道中が主を追い越していた**（前述）。難しくならず、長くなるだけでした。
3. **最終章がダンジョン1本・深さ4の一段の崖だった。**
   しかも「世界の鏡像」は光・闇・物理を弾き弱点が無く、自己回復まで持っていました。
   27.6ラウンドかけて 6/8 で全滅する、**どのビルドでも越えられない壁**です。

最終章は**2本に割って階段に**しました（`鏡面の廻廊` → `相刻の座`。
前段を抜けるまで座への道は開きません＝`need`）。
前段の主「鏡写しの衛士」は物理だけを弾き全体攻撃を持たない**持ち替えを教える一戦**で、
そのあと本番が来ます。

そして**世界の鏡像に「相（そう）」を四つ**持たせました。残HPが下がるたびに
弱点と耐性が入れ替わります（`phases`、`Battle.checkPhase`）。

| 相 | 切り替わる残HP | 弱点 | 耐性 |
| --- | --- | --- | --- |
| 無貌の相 | 開幕 | ― | 光・闇 |
| 焔氷の相 | 72% | 雷 | 炎・氷・**物理** |
| 雷風の相 | 45% | 炎・氷 | 雷・風 |
| 相剋の相 | 20% | 光・闇 | ― |

一枚岩の耐性は、噛み合わないビルドにはただの壁、噛み合うビルドにはただの作業です。
相を回すと、同じ一戦のなかに**どのビルドにも「今なら通る」時間帯が必ず一度は来ます**。
物理を弾くのは第二相だけ。自己回復は取り上げました（長引くだけで難しくならないため）。
切り替わるたびに弱点と耐性がログに出るので、持ち替えの判断ができます。

もう一つ、難易度を上げたときに**第1章がいちばん厳しい**という逆向きの歪みも直しました。
相剋の第1章は全滅24回（他の章はほぼ0）。主人公ひとり・アクセ0・技も数えるほどの場所で
取り巻きを増やしていたためです。難易度による取り巻きの上乗せは、
**主の格が 8 以上になってから**にしました（24回 → 0回）。

同じ理由で「氷獄の女王」（第3章の主）から自己回復を取り上げ、
全体氷攻撃「氷嵐」（35%で凍結）に差し替えました。
自己回復を持つ相手は、格を上げても**危なくならずに長くなる**だけです。
実測で 主戦の残HP 72% → 55%、ラウンドは 5.6 のまま変わりませんでした。

直したあとの実測（標準・24周×3回）――

| 章 | 1章 | 2章 | 3章 | 4章 | 5章 | 6章 |
| --- | --- | --- | --- | --- | --- | --- |
| 勝利時の残HP | 63% | 69% | 70% | 71% | 68% | 65% |
| 主戦の残HP | 48% | 54% | 55% | 61% | 50% | 49% |
| ラウンド | 3.4 | 7.1 | 5.8 | 6.3 | 9.1 | 10.4 |
| 倒れた（24周計） | 0 | 0.3 | 2.7 | 4.3 | 8 | 30 |
| 全滅（24周計） | 0.3 | 0 | 2.3 | 0 | 1 | 11.7 |

のこぎり波は消え、ラウンド数は単調に伸びる階段になりました。
残HPの帯は道中 63〜71%・主戦 48〜61% に収まり、
**危険は終盤に集まります**（倒れる人数が 0 → 30 に伸びていく）。

なお `tools/pacing.js` の数字は1周ごとのばらつきが大きいので
（残HPで±10ポイント動きます）、調整の判断は `--runs 24` 以上で取ること。

`tools/` に、ブラウザを使わずエンジンだけを Node 上に載せて回す
シミュレータがあります（`loadEngine()` が DOM 非依存のファイルだけを読み込みます）。

node tools/check-classplay.js   # 全40職を実際に動かす（就く→技を全部撃つ→戦う→ツリー）
node tools/check-bossgimmick.js # 13体の主の仕掛けが働き、2種のビルドどちらでも崩せるか

node tools/check-classplay.js --diff brutal   # 難易度を変えて全職を通す
node tools/pacing.js            # レベルデザインの点検（章ごとの手応えと、新しいことが起きる頻度）
node tools/pacing.js --tower    # 同じものを試練の塔の5階ごとに
node tools/check-classtrees.js  # 職業ツリー37本の中身を点検（空・重複・文字化け・軸のズレ・2択の偏り）
node tools/check-classtrees.js -v  # 40職ぶんの中身を並べて表示

#### 全職業を動かすテスト（check-classplay.js）

`check-classes.js` は「条件を満たせるか」を計算で確かめる静的な検査で、
その職業が飾りになっていないかまでは見ていません。
`check-classplay.js` は40職すべてを実際に動かして、4つを見ます。

| 見るもの | やること |
| --- | --- |
| 到達 | 本物の転職ゲート（`Unlock.classCheck`）を通す |
| 技 | その職業の技を1つずつ実戦で撃ち、**効くはずの側**に届いたか見る |
| 戦闘 | 格に見合った章の主に、単独と4人で挑ませる |
| ツリー | 職業ツリーの3段すべてを選び、能力値の再計算が通るか見る |

肝は「技」で、**効いた側まで見る**ところです。
以前 `kind: 'util'` の技が敵ではなく自分に返っていて、〈煙玉〉〈解呪波〉〈弱点看破〉
〈縛りの言葉〉が長いあいだ何もしていませんでした。
「何か起きたか」だけを見る判定ではこれを取り逃がします（自分に当たっても何かは起きるため）。
そこで技が出したログ行だけを切り出し、そこに**意図した側のユニット名が出るか**で判定しています。
わざとこの不具合を戻すと、14職が引っかかります。

単独の勝敗は、その職業がどれだけ自前で完結しているかの目安です。
**万象錬成王と零落呪帝は単独 0/12・4人 12/12** ―― 道具と弱体で戦う職業なので、
これは役割どおりで不具合ではありません。落とすのは「4人でも勝てない」ときだけです。
逆に4人だけで測ると意味がなくなります（最上級職の能力値を1/10にしても 12/12 勝ちます）。
